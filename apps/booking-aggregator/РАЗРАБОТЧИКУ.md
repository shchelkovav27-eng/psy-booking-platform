# Агрегатор записи — как работать вместе

Проект лежит в git на том же сервере. Правило одно: **не редактируем файлы
на боевом сервере руками**. Пуш в `main` сам выкладывает сайт.

## Начало работы

Адрес репозитория для работы и выкладки даёт владелец — вместе с доступом.
В репозитории его нет намеренно: сервер и коды входа не должны утекать через код.

```bash
git clone <адрес, который дал владелец>
cd zapis
```

## Выкладка

```bash
git add -A
git commit -m "что сделали"
git pull --rebase        # забрать чужие изменения
git push                 # это и есть деплой
```

После пуша сервер сам:
1. делает бэкап текущей версии в `~/backups/`;
2. раскладывает файлы в `~/public_html/zapis/`;
3. проставляет свежие версии `app.js?v=…` в трёх `index.html` (иначе браузеры
   показывают старый интерфейс);
4. проверяет синтаксис PHP и пишет результат в ответ на push.

Увидели в ответе «синтаксис PHP в порядке» — значит, выложилось.

## Откат

```bash
git revert <хеш>   # и git push
```
Либо на сервере лежат бэкапы каждой выкладки: `~/backups/zapis_ГГГГ-ММ-ДД_ЧЧ-ММ-СС`.

## Что важно знать про этот сервер

* **Telegram с сервера недоступен** — заблокирован хостингом. Бот работает через
  реле `relay/psy_relay.py`, которое крутится на машине координатора: сервер
  копит сообщения в `psy_outbox`, реле их разносит и приносит ответы.
* **SMS Aero и вебхуки — доступны** напрямую.
* Рядом, в `~/public_html/`, живёт другой проект («Трекер»). Его
  деплой теперь исключает папку `zapis`, но лишний раз туда лучше не лезть.
* Секреты (токен бота, ключ SMS) лежат **в базе**, в таблице
  `psy_settings`, а не в файлах. В репозитории их нет и быть не должно.
* Доступы к БД берутся из `../config.php` — он вне репозитория.

## Структура

| Файл | Что делает |
|---|---|
| `index.html`, `spec/`, `koordinator/` | три входа: клиент, специалист, координатор |
| `app.js`, `app.css` | весь интерфейс, один на все роли |
| `api.php` | JSON-API |
| `lib.php` | ядро: база, распределение, бот, SMS, планировщик |
| `cron.php` | планировщик напоминаний (крон раз в 5 минут) |
| `relay/psy_relay.py` | реле Telegram |
| `README.md` | как всё устроено по существу |
