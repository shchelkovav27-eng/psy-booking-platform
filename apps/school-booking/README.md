# Внутренний контур школы — запись к психологу

Вторая установка агрегатора записи, для собственных психологов школы.
Ученица записывается сама по ссылке, куратор в процессе не участвует.

**Адреса**
- ученица — https://booking.example.com/shkola/
- психолог — https://booking.example.com/shkola/spec/
- координатор — https://booking.example.com/shkola/koordinator/

**Чем отличается от пилота (/zapis/)**
- отдельные таблицы `shk_*` в той же базе — данные не смешиваются;
- `sticky = 1`: кто уже был, при повторной записи попадает к своему психологу;
- квота 40 — внутри школы она не для дележа клиентов, а страховка от перегруза;
- импорт состава из Google-таблицы выключен, психологи заводятся руками;
- свой токен бота, свой ключ реле, свой код координатора.

**Как обновлять.** Изначально контур собирался скриптом из кода агрегатора, но школьные
доработки начали протекать в агрегатор — поэтому код отделён в самостоятельный.
Выкладка — `deploy/deploy-rsync.sh` (бэкап на сервере → rsync только этой папки → `php -l`).

**Ссылки на встречи.** У каждого психолога в кабинете стоит своя постоянная
комната (BearJazz) — своя комната главнее автосоздания, Zoom не нужен и
ограничение «один аккаунт = одна встреча за раз» не действует.
